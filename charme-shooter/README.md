# Charme Shooter

Jogo de tiro arcade fofo e viciante com controles touch/teclado.

## Controles
- **Joystick esquerdo** (touch) / **WASD / Setas** (teclado): Movimento
- **Botão direito** (touch) / **Espaço** (teclado): Atirar
- **Clique/Toque na tela** (game over): Reiniciar

## Features
- 3 tipos de inimigos com comportamentos únicos
- Power-ups: vida extra e upgrade de tiro (3 níveis)
- Partículas, shake de tela, estrelas parallax
- SFX sintetizados via Web Audio API
- ~280 linhas, single-file, sem build

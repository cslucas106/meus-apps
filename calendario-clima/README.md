# Calendário Celeste

Um aplicativo de calendário dinâmico que alterna entre o dia (claro com nuvens) e a noite (escuro com estrelas) conforme o horário atual do sistema. Permite também adicionar e gerenciar lembretes por data.

## Funcionalidades
- Mudança automática de tema (Manhã/Dia com nuvens 🌤️ vs Noite estrelada ✨).
- Navegação entre meses.
- Adição e remoção de eventos salvos localmente.

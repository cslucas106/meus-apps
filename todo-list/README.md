# To-Do List App

Um aplicativo web simples e moderno de lista de tarefas desenvolvido com HTML, CSS e JavaScript puros. Os dados são salvos no navegador (`localStorage`), garantindo que suas tarefas não sejam perdidas ao atualizar a página.

## Recursos
- Adicionar, concluir e remover tarefas.
- Filtros para visualizar todas, pendentes ou concluídas.
- Design responsivo e limpo.

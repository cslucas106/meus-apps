# Facada Noir

Jogo mobile de arremesso de facas com atmosfera de mistério (Noir), história dividida em casos investigativos, efeitos sonoros gerados por Web Audio API e salvamento de recordes locais.

## Como Jogar
- Toque na tela ou pressione espaço para arremessar a lâmina.
- Acerte o alvo rotativo sem atingir as outras facas já cravadas.
- Conclua os casos desvendando a história de Midnight City.

# Aventura da Abelha 3D

Jogo 3D completo desenvolvido com **Three.js** e Web Audio API embutida.

## Correções e Melhorias Recentes
- **Orientação Realista Corrigida:** A abelha agora está perfeitamente orientada para olhar diretamente para a direção do voo (frente correta).
- **Controles Unificados e Simultâneos:** Movimente-se pelo joystick ou teclado enquanto usa os botões de Subir/Descer simultaneamente sem travamentos.
- **Gráficos Polidos:** Modelo anatômico detalhado com tórax felpudo, abdômen listrado, ferrão, olhos compostos facetados, iluminação PBR e sombras suaves.

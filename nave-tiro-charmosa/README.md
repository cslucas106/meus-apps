# Estelar — Nave de Tiro Charmosa

Um jogo de nave estilo arcade feito em HTML/CSS/JS puro, sem build.

## Controles
- **Joystick** (canto inferior direito): arraste para mover a nave
- **Botão de tiro** (canto inferior esquerdo): toque/segure para atirar
- **Teclado**: WASD ou Setas para mover, Espaço para atirar, P/Esc para pausar

## Recursos
- Visual "charmoso" com gradientes, brilhos e partículas
- Áudio sintético via Web Audio API (tiros, explosões, power-ups, level up)
- Power-ups: Vida extra, Tiro triplo, Escudo
- Inimigos variados (normal, rápido, tanque) e asteroides
- Sistema de níveis com dificuldade progressiva
- Recorde salvo no localStorage
- Totalmente responsivo (mobile e desktop)

## Como rodar
Abra `index.html` no navegador. Funciona offline.
